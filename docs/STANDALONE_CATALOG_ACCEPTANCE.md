# Standalone Catalog acceptance

- [ ] Public fish catalog shows legacy runtime fish from the pinned source.
- [ ] Legacy fish gallery files are served from Catalog `/media` storage.
- [ ] Public tank catalog is separate from fish catalog and has no fake placeholder records.
- [ ] LOCAL fish CRUD supports name, price, combo display prices, content, publish state and gallery.
- [ ] Tank CRUD supports specifications, price, content, publish state and gallery.
- [ ] Orders synchronization is skipped while standalone mode is enabled.
- [ ] Existing Orders source rows are preserved for future reconnection but hidden from public standalone catalog.
