# NEXORA Product Catalog

HPZ Aquaroom public catalog + Nexora Catalog Admin.

Current implementation follows Thread 60 M0-M2: isolated frontend/backend/PostgreSQL, `/api/v1`, cached Orders read model, canonical `product_id` from CRM Orders, and no cross-CRM database access.

Legacy public UI remains the visual reference and will be migrated dynamically in M5 without an intentional redesign.

See `docs/M0_M2_STATUS.md` and `docs/INT-ORD-CAT-001.md`.
